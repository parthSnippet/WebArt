## 🔧 Setup Instructions

### 1. Generate Secrets
```bash
node generate-secrets.js
```

### 2. Create MongoDB Atlas Cluster
1. Go to https://cloud.mongodb.com
2. Create new cluster
3. Create database user
4. Get connection string
5. Replace `<password>` in connection string

### 3. Setup Cloudinary
1. Go to https://cloudinary.com
2. Sign up for account
3. Get credentials from dashboard
4. Copy Cloud Name, API Key, API Secret

### 4. Setup Email Service

**Option A: SendGrid (Recommended)**
1. Go to https://sendgrid.com
2. Create account
3. Create API key
4. Use these settings:
   - HOST: `smtp.sendgrid.net`
   - PORT: `587`
   - USER: `apikey`
   - PASS: Your API key

**Option B: AWS SES**
1. Go to AWS SES console
2. Verify sender email/domain
3. Create SMTP credentials
4. Use provided settings

**Option C: Gmail (Development only)**
1. Enable 2FA on Gmail
2. Generate App Password
3. Use these settings:
   - HOST: `smtp.gmail.com`
   - PORT: `587`
   - USER: Your Gmail
   - PASS: App Password

### 5. Domain Setup
1. Purchase domain from registrar
2. Point A records to your server IP:
   - `yourdomain.com` → Server IP
   - `api.yourdomain.com` → Server IP
3. Wait for DNS propagation (up to 48 hours)

### 6. SSL Certificate

**Option A: Let's Encrypt (Free)**
```bash
sudo certbot --nginx -d yourdomain.com -d api.yourdomain.com
```

**Option B: Cloudflare (Free)**
1. Add domain to Cloudflare
2. Update nameservers
3. Enable SSL/TLS (Full)

## 🚨 Security Reminders

1. **Never commit** `.env.production` or `production-secrets.txt` to git
2. **Use strong passwords** - minimum 16 characters
3. **Rotate secrets** regularly (every 90 days)
4. **Limit database access** - use specific IP whitelist when possible
5. **Enable 2FA** on all service accounts
6. **Monitor logs** for suspicious activity
7. **Keep dependencies updated** - run `npm audit` regularly

## 📝 Notes

- Store production secrets in a secure password manager
- Keep backup of all credentials
- Document any custom configurations
- Share access only with authorized team members
